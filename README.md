# Creatives Digital Agency & Institute 🚀

Modern, high-performance website for **Creatives Digital Agency & Institute** (`creativesdigitalagency.com`), combining high-end digital solutions (Web Development, Digital Marketing, 3D Branding) with a Zero-to-Hero training institute for beginners.

Built with **Next.js 15 (App Router)**, **TypeScript**, **Tailwind CSS (Luxury Dark Glassmorphism)**, and **Prisma ORM**.

---

## 🌟 Key Features

* **⚡ Ultra-Fast Next.js 15 App Router:** Server-side rendering (SSR) for sub-second page loads.
* **🎨 Avista Luxury Dark Glassmorphism:** Deep `#080B11` canvas with electric purple (`#8B5CF6`) and cyber cyan (`#06B6D4`) glowing gradients.
* **✦ Avista Signature Marquee Ticker:** Smooth infinite scrolling horizontal ticker.
* **📊 Trust Builder Numerical Counters:** 150+ Projects, 99% Satisfaction, 500+ Students, 15+ Global Partners.
* **💼 Services Grid:** Bordered glass cards for SEO, Web & App Dev, 3D Branding, Video Production, UI/UX, and E-Commerce.
* **🎯 4-Step Execution Framework:** Discovery &rarr; Design & Prototype &rarr; Development &rarr; Launch & Scale.
* **📂 Interactive Case Studies Gallery:** Category filter tabs (Commercial Vehicles, Industrial, Retail, Web) with interactive modal popups.
* **🎓 The Institute Section:** Zero-to-Hero beginner curriculum with expandable course syllabuses and direct WhatsApp advisor chat.
* **💎 Value-Driven Pricing Tiers:** Interactive toggle for Agency Client Packages & Institute Batch Fees.
* **⭐ Client & Student Testimonials:** High-trust review cards with 5-star ratings and verified badges.
* **❓ FAQ Accordion:** Common answers for agency deliverables and beginner course prerequisites.
* **💬 Speed-to-Lead Hub & Floating WhatsApp:** 15-minute response pledge and interactive lead form saved via Prisma ORM.

---

## 🛠️ Tech Stack

* **Framework:** Next.js 15 (App Router)
* **Language:** TypeScript
* **Styling:** Tailwind CSS + Custom Glassmorphism & Neon Glow Utilities
* **Icons & Animation:** Lucide React & Framer Motion
* **Database & ORM:** Prisma ORM with SQLite (ready for PostgreSQL/MySQL in production)

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/naseemulhaq4422/creativesdigitalagency.git
cd creativesdigitalagency
```

### 2. Install dependencies
```bash
npm install
```

### 3. Setup Database & Seed Data
```bash
npx prisma generate
npx prisma db push
npx tsx prisma/seed.ts
```

### 4. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) (or your chosen port) to view the website.
